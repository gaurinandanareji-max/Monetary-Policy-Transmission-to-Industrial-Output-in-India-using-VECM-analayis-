# Monetary-Policy-Transmission-to-Industrial-Output-in-India-using-VECM-analayis-
Monetary Policy Transmission to Industrial Output in India

Project Overview

Studied the transmission of monetary policy to industrial output in India using time-series data.

Variables Studied

- Index of Industrial Production (IIP)
- Repo Rate
- Bank Credit

Methods Used

- Augmented Dickey-Fuller (ADF) Test
- Johansen Cointegration Test
- Vector Error Correction Model (VECM)
- Impulse Response Analysis
- Forecast Error Variance Decomposition

Tools Used

- R
- Time-Series Econometrics
- Excel
